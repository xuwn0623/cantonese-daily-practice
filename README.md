# 粤语学习台

个人粤语学习与朋友分享用的静态网页。以香港粤语为主，48 次课程，每次目标 45 分钟、每周 4 次，覆盖粤拼与发音基础、听辨、开口练习及日常社交场景。

## 使用

打开已发布网页后选择今日练习。首次启用粤语识别约下载 249 MB，之后优先读取浏览器缓存。电脑 Chrome 优先；手机能否运行取决于可用内存。示范音使用访问者设备的粤语音色，需要中文（香港）或粤语音色。

录音和识别在设备浏览器中处理，不上传练习音频；无需语音 API 密钥、绑卡或订阅。学习进度保存在各自浏览器，可从「使用与备份」导出及恢复，没有自动跨设备同步。

## 能力边界

文字识别匹配不能证明发音准确；目前没有可靠的声母、韵母、韵尾或连读音素评分。单字声调功能用于观察音高走势。课程为学习工作稿，尚未由粤语教师逐项审核。

仓库根目录可通过 GitHub Pages 发布，保留 `.nojekyll`。网页支持根目录和项目子目录。模型及运行时来源和许可证见 [THIRD_PARTY.md](THIRD_PARTY.md)，托管平台有容量与流量限制。
