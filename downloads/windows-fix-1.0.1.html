下载 Windows 修复补丁

  1. 下载上面的 ZIP 并解压，会得到 start-windows.cmd 和 launcher-windows-fix.py 两个文件。
  2. 把这两个文件一起复制到原来的 cantonese-desktop-1.0.0 文件夹中，与原有 launcher.py、manifest.json、site 文件夹放在同一层。保留原文件，不需要覆盖或删除。
  3. 以后双击新增的 start-windows.cmd。出现“学习台已启动”后，保持黑色窗口开启，浏览器打开 http://127.0.0.1:8779/。

如果没有自动打开浏览器，在原文件夹的地址栏输入 cmd 并回车，再复制下面整行命令并回车：

py -3 launcher-windows-fix.py
